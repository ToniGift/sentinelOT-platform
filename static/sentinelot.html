        05Equipment list

        Tags are ISA-style. IT equipment uses plain asset-class prefixes. The first digit of a number is the area: 1 line 1, 2 line 2, 3 network security, 4 enterprise and DMZ, 5 utilities, 6 operations and supervisory servers and workstations.

        TagNameTypeLevelAlarmOps tagOrigin

        FT-501 is a drawn device, so it has an asset tag. LT-501, PT-501, TT-101 and ST-101 are signal tags: a measurement on a drawn device, read through another one. TIC-101 is the sealer temperature controller, a function inside PLC-101. A highlighted row is a tag in alarm, or one whose limit change is blocked or would miss an alarm.

        06How it works

        1. N1

          Listen

          A sensor on a mirror port reads every frame between the masters and the PLC. It never writes to the control network.

        2. N2

          Judge

          Rules check who is talking, which function code they used and whether the value fits the engineering limits.

        3. N3

          Explain

          AI adds asset context, maps the activity to MITRE ATT&CK for ICS and tells the analyst what to do first. It recommends and never acts.

        In the live demo a fixed rule raises the alarm and the AI only explains it. The recorded alerts come from the full project, where five AI agents triage each alert and code checks their output. Read the code on GitHub.
